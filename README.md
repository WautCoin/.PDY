# .PDY

**PDY** is a lightweight cryptocurrency token project.

## Overview

PDY provides a simple, transparent token structure built for the WautCoin ecosystem.

## Features

- Minimal, auditable token contract
- Community-driven governance
- Transparent supply and distribution

## Getting Started

Clone the repository and follow the setup instructions to interact with the PDY token.

```bash
git clone https://github.com/WautCoin/.PDY.git
cd .PDY
```
